# Atlas Market v1.0.0

Atlas Market v1.0.0 is the first production release of the authenticated, paper-trading-only Atlas workspace.

Production: https://atlas-market.netlify.app

## Highlights

- Institutional workspace interface inspired by professional trading platforms
- Permanent application shell with sidebar, top navigation, breadcrumbs, and scroll-contained workspace content
- Dedicated workspaces for Dashboard, Markets, Scanner, Watchlist, Portfolio, Risk, Orders, Strategies, Backtesting, Research, Atlas Copilot, Reports, System Health, and Settings
- React Router route ownership with direct workspace URLs
- Route-level `React.lazy` loading and independent production workspace chunks
- Responsive desktop, tablet, and narrow/mobile shell
- Paper-trading-only order workspace with simulated order entry, status, accounting context, lifecycle, and journal surfaces
- Advisory-only Atlas Copilot with explicit safety boundaries
- Portfolio, risk, opportunity, research, report, and diagnostic workspaces
- Netlify production deployment with SPA direct-route refresh support
- Invite-only Netlify Identity authentication with recovery, session restoration, logout, explicit owner roles, and fail-closed verification
- Authenticated and tenant-scoped Netlify Functions with server-bound CSRF protection; only `health` and `watchlist` remain intentional public reads
- Canonical PostgreSQL paper account, immutable execution ledger, durable positions, transactional entry/exit accounting, and retry-safe idempotency
- Explicit live, delayed, stale, degraded, mock, unavailable, and unknown market-data provenance
- GitHub Actions enforcement of lint, tests, build, performance, API-control inventory freshness, migration safety, sensitive-material scanning, and generated-artifact checks

## Limitations

- Atlas Market does not support live brokerage execution.
- Atlas Market does not provide financial advice.
- Paper simulation results do not guarantee real-world outcomes.
- Data-provider availability may vary by keys, provider uptime, and configured provider mode.
- The current production fallback is visibly labeled `MOCK DATA`; it must not be interpreted as live market evidence.
- Production backup/restore execution, retention evidence, and disaster-recovery drills remain owner-operated tasks.
- Serverless provider caches and request budgets remain process-local.
- Some workspace summaries are intentionally concise in v1.0.0.
- Environment keys are required for provider-backed market data.

## Safety Boundaries

Atlas is paper-trading-only. Atlas Copilot is advisory-only. The application does not create live orders, route broker instructions, bypass paper-trading controls, or turn AI output into autonomous execution.
